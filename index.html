Lisnoti

Lisnoti (/lɪzˈnəʊtiː/) is a free sans serif font for everyday use, with clear, unambiguous letters and coverage of Latin, Greek, Cyrillic and Devanagari character sets.

It is particularly strong for math, science and actuarial work, including typesetting equations.

If you’re interested in why Lisnoti exists, see this blog article.

Equations

Lisnoti has a full OpenType MATH table, which means it can be used to typeset equations properly in LaTeX (using LuaLaTeX) and in Word (choose Lisnoti as the equation font).

The equations on this page are converted by Temml, a small open-source library, and set by the browser from Lisnoti’s MATH table.

LuaLaTeX

With Lisnoti installed, use the following at the start of your LaTeX document to set the math font to Lisnoti. The last line ensures \mathcal produces the correct (chancery) capitals.

\usepackage{unicode-math}
\setmainfont{Lisnoti}
\setmathfont{Lisnoti}
\setmathfont{Lisnoti}[range=\mathcal, StylisticSet=1]

The second line of the snippet sets the main font to Lisnoti – delete the line if you don’t want that.

Get Lisnoti

There are three ways to use Lisnoti, all free.

1. Install it

Download the four fonts and install them in the usual way.

  • Windows: select the files, right-click and choose Install.
  • Mac: open the files in Font Book.

Lisnoti-ttf.zip

2. Link to lisnoti.com

Add the following line to each page’s <head>:

<link rel="stylesheet" href="https://lisnoti.com/lisnoti.css">

and name the font in your CSS:

body { font-family: Lisnoti, sans-serif; }

Pages fetch only the subsets they need: about 32 KB per style for English text.

3. Host it yourself

Download Lisnoti-woff2.zip, copy the folder into your site and link its lisnoti.css. Keep the stylesheet in the folder with its font files.

For one file per style, or for text with separately encoded accents, use Lisnoti-woff2-monolithic.zip and its lisnoti-monolithic.css.
