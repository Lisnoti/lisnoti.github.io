Lisnoti

Lisnoti (/lɪzˈnəʊtiː/) is a proportional sans serif font designed for general use but with consideration also given to making it work

  • in maths, science and actuarial contexts, and
  • for writing computer code.

Lisnoti is available in regular, italic, bold and bold-italic variants in OpenType (.ttf) and web (.woff2) formats under the SIL Open Font Licence (OFL).

If you’re interested in why Lisnoti exists, please see this article.

Installing Lisnoti

Using Lisnoti locally

If you want to install Lisnoti on machines for local use then the OpenType font files are here.

Using Lisnoti for websites

The first option is to host the font files yourself (i.e. store them with the rest of your website), in which case the sliced web fonts and their style sheet are here, and the whole-font versions, one file per style, are here.

The second option is to use the Lisnoti font delivery service, which simply amounts to referencing the style sheet on this site. (Background reading: Google’s guidance on its font delivery service.)

In essence, you want

  • to reference the lisnoti.css file at the root of this website, either with a link in your pages or with one line at the top of your own style sheet, and then
  • to specify Lisnoti as a font in your styles (just like any other font).

The stylesheet serves the font in slices, so a page fetches only the pieces it uses: a page of English text fetches about 27 KB for each weight it sets, and the maths, Greek, Cyrillic and symbol slices only when a character calls for them. If you would rather have one file per style (about 400 KB each), or your page sets decomposed phonetic text, link lisnoti-full.css instead.

Here’s a skeleton example:

<head>
<link rel="stylesheet" href="https://lisnoti.com/lisnoti.css">
<style>
body {
  font-family: "Lisnoti", sans-serif;
}
</style>
</head>

If you would rather not put a link in every page, reference the style sheet from the top of your own style sheet instead, which is what this page does: 

@import url("https://lisnoti.com/lisnoti.css");

Key features

Lisnoti is derived from Noto's sans serif fonts, but with the following adaptions:

  1. Reliable distinction of upper case I vs lower case l, and upper case O vs zero 0.
  2. Consistent arithmetic, comparison, logic, set, n-ary and other maths operators, e.g.
    • arithmetic: − × ÷ ± ∓ ∞ (NB Noto Sans gets the minus sign wrong)
    • comparison: ≤ ≠ ≥ ≈ ≡ ≢ ∝
    • logic: ¬ ∧ ∨ ⊻ ⊤ ⊥ ⊦
    • set: ∩ ∪ ∈ ∉ ⊂ ⊃ ⊆ ⊇ ∅
    • n-ary: ∑ ∏ ⋀ ⋁ ⋂ ⋃
    • other: ∫ ∂ √ Δ ∇ ∀ ∃
  3. Greek and Cyrillic letters – maths and logic make frequent use of Greek letters and occasionally Cyrillic ones too.
  4. Consistently formatted digit and – if available – Roman letter sub and superscripts:

    • subscript: ₀₁₂₃₄₅₆₇₈₉₍₎₊₋ₐₑₕᵢⱼₖₗₘₙₒₚᵣₛₜᵤᵥ₝ₓ₞₟
  5. A reasonable selection of symbols, including

Construction

Lisnoti is built from Noto’s sans serif fonts. What it changes, and why, is set out in the Lisnoti GitHub repo.
